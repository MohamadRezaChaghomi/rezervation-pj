# Rezervation Project

## 📋 Overview

Rezervation Project is a comprehensive reservation system developed for tourism and hospitality services. This project includes a user-facing website built with the Trizen theme and an admin dashboard for managing reservations, blogs, reviews, and reports.

This project was developed by MohamadReza Chaghomi as part of a software engineering course, implementing modern web technologies and responsive design for a complete reservation platform.

## ✨ Key Features

### ✅ Core Features
- **User Interface**: Responsive tourism website with RTL support
- **Admin Dashboard**: Complete admin panel for managing the system
- **Reservation Management**: Hotel, tour, and activity booking system
- **Blog Management**: Content management for travel blogs
- **Review System**: User reviews and ratings
- **Reports Dashboard**: Analytics and reporting tools
- **Entertainment Management**: Active/inactive entertainment listings

### 🚀 Extended Features
- **Multi-language Support**: Persian (RTL) and English interfaces
- **Interactive Maps**: Integrated mapping for locations
- **Date Pickers**: Advanced date selection with Persian calendar
- **Charts and Analytics**: Visual data representation
- **File Upload**: Multi-file upload capabilities
- **Rich Text Editor**: CKEditor integration
- **Real-time Updates**: Dynamic content loading

## 🛠️ Technology Stack

### Frontend
- **HTML5**: Semantic markup
- **CSS3**: Custom styling with Bootstrap
- **JavaScript**: jQuery and vanilla JS
- **Bootstrap**: Responsive framework
- **RTL Support**: Right-to-left layout for Persian

### Libraries & Tools
- **jQuery 3.4.1**: DOM manipulation

### Development Tools
- **Git**: Version control
- **VS Code**: Development environment

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Local server (optional for development)

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/MohamadRezaChaghomi/rezervation-pj.git
   cd rezervation-pj
   ```

2. Open the project in your browser
   - For the main theme: Open `Theme/trizen/index.html`
   - For RTL version: Open `Theme/trizen-rtl/index.html`

### Usage
- **User Website**: Navigate through the tourism website to explore services
- **Admin Panel**: Access admin dashboards in `Theme/trizen-rtl/MohamadReza-Chaghomi-Part/`
